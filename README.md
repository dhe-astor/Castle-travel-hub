Welcome to Castle Travel Hub — a lightweight, responsive travel site template showcasing destinations, galleries, packages, and vehicle options.

## Demo

Open the site locally: [castle travel hub/index.html](castle travel hub/index.html)

## Preview

![Hero preview](Images/hero/premium_photo-1697729438401-fcb4ff66d9a8.avif)

## Features

- Clean, responsive layout using CSS
- Destinations, Packages, Gallery and Contact pages
- Lightweight JavaScript for interactions (`jss/script.js`)
- Ready-to-use images in `Images/` and `assets/`

## Quick Start

1. Open the project folder in your file explorer.
2. Open `castle travel hub/index.html` in your browser.

Or serve locally with Python (recommended for local routing):

```bash
python -m http.server 8000
# then visit http://localhost:8000/castle%20travel%20hub/index.html
```

## Structure

- `castle travel hub/` — site pages (index, about, gallery, etc.)
- `css/` — stylesheets
- `Images/` — image assets
- `jss/` — JavaScript
